# Security Policy

## Research Scope

AppleSpywareResearch is intended for controlled cybersecurity research and security education.

Research should only be performed against systems, applications, simulators, and devices that the researcher owns or has explicit authorization to test.

## Responsible Research

Do not use this project for:

- unauthorized access
- surveillance of third parties
- credential theft
- unauthorized data collection
- privacy bypass
- persistence on third-party devices
- data exfiltration
- deployment of malicious software

Research involving vulnerabilities should prioritize controlled reproduction, documentation, defensive analysis, and responsible disclosure.

## Sensitive Information

Do not commit:

- credentials
- API keys
- signing certificates
- private keys
- provisioning profiles
- personal data
- real victim or target information
- proprietary exploit material

Use synthetic or test data whenever possible.

## Vulnerability Disclosure

If research conducted through this project identifies a previously unknown security vulnerability, avoid publishing operational exploit details before the affected vendor has had a reasonable opportunity to investigate and remediate the issue.
